# Dashboard screenshot

This folder holds the PNG export of the Power BI report page.

| File | Page |
| --- | --- |
| `model-performance.png` | Model Performance |

## How to export it

1. Open `powerbi/real-estate-dashboard.pbix` in Power BI Desktop.
2. Screenshot the report canvas at 100% zoom — or **File → Export → Export
   report to PDF** and crop to PNG.
3. Save here as `model-performance.png`.
4. In the root `README.md`, delete the `<!-- DASHBOARD SCREENSHOT ... -->`
   comment wrapper. The image markdown inside is already written.

Export at roughly 1600 px wide so the KPI cards stay legible on GitHub.
